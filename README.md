# Bank Projesi

Bu proje bir banka kredi başvuru sistemi uygulamasıdır.

## Özellikler

- Bireysel müşteri yönetimi
- Kurumsal müşteri yönetimi
- Kredi başvuru işlemleri
- Kredi türleri yönetimi
- Kullanıcı yetkilendirme sistemi

## Teknolojiler

- .NET 8
- Entity Framework Core
- MediatR
- AutoMapper
- JWT Authentication

Bugbot test
